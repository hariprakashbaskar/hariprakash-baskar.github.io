# Hariprakash Baskar — Personal Portfolio

A responsive, animated personal portfolio built with:
- HTML5
- Bootstrap 5.3
- Bootstrap Icons
- Custom CSS
- Vanilla JavaScript

## Run locally
Just open `index.html` in a browser.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace the LinkedIn URL with your real LinkedIn profile.
3. Put your actual resume at:
   `assets/Hariprakash_Baskar_Resume.pdf`

## Free hosting options
### GitHub Pages
1. Create a public GitHub repository.
2. Upload all files/folders from this project.
3. GitHub → Settings → Pages.
4. Choose **Deploy from branch** → `main` → `/root`.
5. Save. Your site will get a free `github.io` address.

### Netlify
Drag the project folder into Netlify's deploy area, or connect the GitHub repository.

### Cloudflare Pages
Connect the GitHub repository and select the root folder. No build command is required.

## Design direction
The site intentionally uses a premium dark "quality engineering / AI" aesthetic, animated glass cards, responsive Bootstrap layout, timeline storytelling, skill clouds, project cards, light/dark mode and a strong recruiter-oriented hero.
